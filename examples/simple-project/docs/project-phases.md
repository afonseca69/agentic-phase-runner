# Project Phases

## F01 — Discovery

Goal: create the first project note and confirm the safety rules.

Acceptance:
- `notes/discovery.md` exists or is proposed.
- Safety rules are acknowledged.
- A summary is written.

## F02 — First artifact

Goal: create a small project artifact.

Acceptance:
- `notes/first-artifact.md` exists or is proposed.
- Validation steps are documented.
- A summary is written.
